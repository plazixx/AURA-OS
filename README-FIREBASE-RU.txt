AURA-OS — первый этап подключения Firebase

Что добавлено:
- auth.html — страница входа и регистрации;
- js/firebase-auth.js — Firebase Authentication через CDN-модули;
- ссылка «Аккаунт» в боковой навигации;
- firestore.rules.example — пример правил для пользовательских документов.

Перед проверкой:
1. В Firebase Console → Authentication → Способ входа проверь, что «Электронная почта/Пароль» включён. По твоему скриншоту он уже включён.
2. Firebase Console → Authentication → Settings → Authorized domains: добавь домен, на котором будет размещён сайт. Для локальной разработки используй локальный сервер (например, Live Server в VS Code), не открывай auth.html двойным щелчком через file://.
3. Запусти сайт через локальный сервер и открой auth.html. Попробуй создать тестовый аккаунт.
4. Не публикуй firestore.rules.example как правила автоматически без проверки структуры данных. После интеграции Firestore нужно применить проверенные правила в консоли Firebase.

ВАЖНО — границы этого этапа:
- Реализованы регистрация и вход по email/паролю.
- Данные разделов пока НЕ синхронизируются с Firestore.
- Локальные данные не очищаются и не переносятся автоматически.
- Не отключай существующие способы хранения данных, пока не будет готова и проверена миграция.
- Конфигурация веб-приложения содержит публичный идентификатор API; безопасность обеспечивается правилами Firestore и настройками Authentication, а не сокрытием этого объекта. Никому не передавай приватные ключи сервисного аккаунта.
