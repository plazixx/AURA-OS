AURA-OS — облачная синхронизация через Firebase Firestore

Что подключено в этой версии:
- js/firebase-auth.js — существующая авторизация email/пароль;
- js/cloud-sync.js — синхронизация ключей localStorage, начинающихся с aura-, с Firestore;
- страницы главная, задачи, проекты, финансы, Мёртвая книга, трекер дня и календарь подключают модуль синхронизации;
- данные хранятся в users/{UID}/data/{ключ-хранилища}, отдельно для каждого вошедшего пользователя.

ПЕРЕД ПУБЛИКАЦИЕЙ:
1. Сделай резервную копию текущего репозитория на GitHub (можно скачать ZIP старой версии).
2. Firebase Console → Firestore Database → Rules: опубликуй правила из firestore.rules.example. Они разрешают доступ только вошедшему пользователю к документам с его UID.
3. Firebase Console → Authentication → Sign-in method: Email/Password должен быть включён.
4. Загрузи файлы этой версии в корень репозитория, сохранив структуру папок. Не загружай лишнюю вложенную папку AURA-OS-main внутрь репозитория — загружай её содержимое.
5. Дождись завершения GitHub Pages deployment и открой сайт по HTTPS.
6. Войди в AURA-OS. Внизу появится сообщение о состоянии синхронизации. При первом входе существующие локальные ключи aura-* будут загружены в облако, если соответствующих документов ещё нет. Если документ уже существует, облачная версия заменит локальную.
7. Проверка: создай тестовую задачу на ПК, подожди несколько секунд, открой сайт на телефоне под тем же аккаунтом и проверь, появилась ли задача.

ВАЖНО:
- Этот модуль синхронизирует значения localStorage с ключами, начинающимися на aura-. Новые и существующие разделы, использующие такие ключи, будут синхронизироваться автоматически.
- Первичная синхронизация может перезагрузить страницу, если данные были восстановлены из облака.
- Не включай публичное чтение/запись Firestore. Не удаляй данные сайта во время проверки.
- При одновременном редактировании одного и того же раздела на двух устройствах последнее сохранение может заменить более раннее. Это базовая синхронизация, не система разрешения конфликтов.
- Это подготовленная интеграция кода, но её нельзя считать проверенной в твоём Firebase до публикации файлов и теста на ПК и телефоне.
